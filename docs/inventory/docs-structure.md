## Topic taxonomy of the official product documentation

Merged taxonomy. Rows tagged [read] come from `documentation.ts` or the fetched nav;
rows tagged [inferred] come from routes/UI/crates only.

1. **Getting started** [read]: install per OS, first collection, first request.
2. **Core concepts** [inferred from UI]: organization → project → workspace →
   collection/folder → request; scratch pad; environments (base/sub/global) and private
   environments [read: `README.md` "Private Environments"]; cookie jar; request
   settings; response inspection (body, headers, timeline, cookies).
3. **Protocols** [inferred from routes `...debug.request.*`,
   `ui/components/panes/grpc-request-pane.tsx`, `ui/components/websockets/`,
   `graph-ql-explorer/`]: REST/HTTP, GraphQL, gRPC, WebSocket, SSE; Socket.IO
   components exist (`ui/components/socket-io/`).
4. **Template tags and variables** [read `/insomnia/template-tags`]; Nunjucks syntax
   and key maps [read `/insomnia/key-maps`].
5. **Authentication** [inferred from `src/network` auth type strings: apikey, basic,
   digest, netrc, ntlm, oauth1, oauth2; modal `oauth-authorization-status-modal.tsx`].
6. **Scripting and testing** [read `/insomnia/pre-request-script`,
   `/insomnia/after-response-script`, `/insomnia/scripts`, `/insomnia/unit-testing`]:
   pre-request scripts, after-response scripts, assertions, test suites, collection
   runner (`routes/...debug.runner.tsx`, `ui/components/panes/runner-*.tsx`).
7. **Design documents** [read `docsWorkingWithDesignDocs`]: OpenAPI editor, visual
   preview, linting (`common/spectral-ruleset-validator.ts`), generate collection from
   spec (`...spec.generate-request-collection.tsx`).
8. **Mocking** [read `/insomnia/api-mocking` and `...mock-server.*` routes]: cloud or
   self-hosted mock server, mock routes, generate requests from mocks.
9. **Storage and sync** [read nav "Storage": Local vault, Cloud sync, Git sync;
   `/insomnia/git-sync`, `/insomnia/version-control-sync`]: local vault, cloud sync,
   Git sync (branches, commits, diff, push/pull, credentials), Insomnia Sync branches
   and snapshots (`...insomnia-sync.*` routes), private environments, E2EE.
10. **Import, export, migration** [read `/insomnia/import-export-data`; formats read
    from `common/import.ts` + `ui/components/modals/import-modal/`: insomnia v4/v5,
    postman, har, openapi/openapi3, swagger, curl, wsdl, json/yaml].
11. **Plugins** [read `/insomnia/introduction-to-plugins`; `src/plugins/`,
    `ui/components/settings/plugins.tsx`, `examples/insomnia-plugin-sandbox-demo/`].
12. **CLI (Inso)** [read `/inso-cli/introduction`; commands read from
    `packages/insomnia-inso/src/commands/`: `run`, `lint`, `export`].
13. **MCP clients** [read nav + `documentation.ts`; routes
    `...workspace.$workspaceId.mcp.tsx`, `ui/components/mcp/`].
14. **Account, organizations, collaboration** [read nav "Account management" and
    "Security": RBAC, SSO, SCIM; routes `organization.*`,
    `organization.$organizationId.collaborators*`].
15. **Settings and customization** [inferred from `ui/components/settings/`]: general
    preferences, fonts/key maps, themes (`theme-panel.tsx`), keyboard shortcuts
    (`shortcuts.tsx`), certificates (`workspace-certificates-modal.tsx`, `cacert.*`,
    `clientcert.*`), AI/LLM settings (`ai-settings.tsx`,
    `settings/llms/{claude,gemini,gguf,openai}.tsx`), proxy/allowlist [read reference
    nav].
16. **Reference** [read reference nav]: keyboard shortcuts, proxy and allowlist, API
    specs, collected data.
17. **Support** [read]: FAQ, changelog/release cadence.
