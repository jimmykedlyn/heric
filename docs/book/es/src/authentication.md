# Autenticación

La autenticación de request soporta los esquemas del cliente original:

| Esquema | Estado |
|---|---|
| Basic | previsto para M3 |
| Bearer | previsto para M3 |
| Digest | previsto para M3 |
| NTLM | previsto para M3 |
| OAuth 1.0 | previsto para M3 |
| OAuth 2.0 (todos los grants) | previsto para M3 |
| AWS SigV4 | previsto para M3 |
| Hawk | previsto para M3 |
| ASAP | previsto para M3 |
| API key | previsto para M3 |
| Netrc | previsto para M3 |

Las credenciales escritas en el panel de autenticación no se incluyen en los
archivos exportados, salvo que lo permitas, como en el comportamiento
original.
