# Primeros pasos

Heric organiza el trabajo como el cliente original: una **organization**
contiene **projects**, un project contiene **workspaces**, y un workspace
reúne una collection de requests, environments y carpetas.

1. Crea un project. Se crea un project local para ti en el primer uso.
2. Crea un workspace dentro del project.
3. Se crean automáticamente un environment base y un cookie jar.
4. Agrega un request al workspace y envíalo.

La ventana principal tiene una barra lateral con tus collections, el editor
del request y un panel de respuesta con el body, los headers y la timeline de
la última ejecución.
