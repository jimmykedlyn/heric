# Protocolos

Heric soporta los protocolos del cliente original además de HTTP simple. Cada
página documenta cómo usar el protocolo dentro de la aplicación.

- [GraphQL](graphql.md) — queries, mutations e introspección de schema.
- [gRPC](grpc.md) — archivos proto y reflection del servidor.
- [WebSocket](websocket.md) — conexiones y log de mensajes.
- [Server-Sent Events](sse.md) — respuestas en streaming.
