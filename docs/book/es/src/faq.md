# FAQ

## ¿Heric tiene vínculo con Insomnia o con Kong?

No. Heric es un proyecto independiente que busca compatibilidad.

## ¿Puedo seguir usando Insomnia mientras uso Heric?

Sí. La importación copia los datos; el directorio original nunca se modifica.

## ¿Dónde están mis datos?

En un directorio de datos de Heric, en la ubicación estándar de tu
plataforma. Ver
[Requests y environments](requests-and-environments.md) para saber cómo se
guardan los secrets.

## ¿Qué plataformas son compatibles?

Windows x86_64, Linux x86_64 y macOS en Apple Silicon e Intel.

## ¿Y el cloud sync?

Fuera de alcance. Ver `docs/out-of-scope.md` del proyecto.
