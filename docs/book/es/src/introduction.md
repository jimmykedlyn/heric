# Introducción

Heric es un cliente de API nativo, escrito en Rust, con interfaz egui. El
objetivo es alcanzar la paridad de funcionalidades con el cliente de API
Insomnia y la compatibilidad con sus datos.

Este libro documenta la aplicación: instalación, uso diario y cada área de
funcionalidad. Está disponible en [inglés](../en/), [portugués](../pt-BR/) y
español.

Heric es un proyecto independiente y no tiene vínculo con Kong Inc.
"Insomnia" aparece en este libro solo para describir compatibilidad y
migración.
