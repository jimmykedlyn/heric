# Protocols

Heric supports the protocols of the original client beyond plain HTTP.
Each page documents how to use the protocol inside the application.

- [GraphQL](graphql.md) — queries, mutations and schema introspection.
- [gRPC](grpc.md) — proto files and server reflection.
- [WebSocket](websocket.md) — connections and message log.
- [Server-Sent Events](sse.md) — streaming responses.
