# FAQ

## Is Heric affiliated with Insomnia or Kong?

No. Heric is an independent project that aims for compatibility.

## Can I keep using Insomnia while using Heric?

Yes. Import copies data; the original directory is never modified.

## Where is my data stored?

In a Heric data directory under your platform's standard location. See
[Requests and environments](requests-and-environments.md) for how secrets
are stored.

## Which platforms are supported?

Windows x86_64, Linux x86_64 and macOS on Apple Silicon and Intel.

## What about cloud sync?

Out of scope. See the project's `docs/out-of-scope.md`.
