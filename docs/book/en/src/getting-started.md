# Getting started

Heric organizes work the same way the original client does: an
**organization** contains **projects**, a project contains **workspaces**,
and a workspace holds a collection of requests, environments and folders.

1. Create a project. A local project is created for you on first launch.
2. Create a workspace inside the project.
3. A base environment and a cookie jar are created automatically.
4. Add a request to the workspace and send it.

The main window has a sidebar with your collections, a request editor, and a
response panel with the body, headers and timeline of the last execution.
