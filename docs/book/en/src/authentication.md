# Authentication

Request authentication supports the schemes of the original client:

| Scheme | Status |
|---|---|
| Basic | planned M3 |
| Bearer | planned M3 |
| Digest | planned M3 |
| NTLM | planned M3 |
| OAuth 1.0 | planned M3 |
| OAuth 2.0 (all grants) | planned M3 |
| AWS SigV4 | planned M3 |
| Hawk | planned M3 |
| ASAP | planned M3 |
| API key | planned M3 |
| Netrc | planned M3 |

Credentials entered in the auth panel are not written to export files unless
you allow it, matching the original behavior.
