# Introduction

Heric is a native API client built in Rust with an egui interface. It aims
for feature parity with the Insomnia API client and compatibility with its
data.

This book documents the application: installation, everyday use, and every
feature area. It is available in [English](../en/), [Portuguese](../pt-BR/)
and [Spanish](../es/).

Heric is an independent project and is not affiliated with Kong Inc.
"Insomnia" appears in this book only to describe compatibility and
migration.
