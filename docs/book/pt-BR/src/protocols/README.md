# Protocolos

Heric suporta os protocolos do cliente original além do HTTP simples. Cada
página documenta como usar o protocolo dentro da aplicação.

- [GraphQL](graphql.md) — queries, mutations e introspecção de schema.
- [gRPC](grpc.md) — arquivos proto e reflection do servidor.
- [WebSocket](websocket.md) — conexões e log de mensagens.
- [Server-Sent Events](sse.md) — respostas em streaming.
