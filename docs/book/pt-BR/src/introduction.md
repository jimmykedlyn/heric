# Introdução

Heric é um cliente de API nativo, escrito em Rust, com interface egui. O
objetivo é alcançar paridade de funcionalidades com o cliente de API
Insomnia e compatibilidade com os dados dele.

Este livro documenta a aplicação: instalação, uso no dia a dia e cada área
de funcionalidade. Ele está disponível em [inglês](../en/), português e
[espanhol](../es/).

Heric é um projeto independente e não tem vínculo com a Kong Inc.
"Insomnia" aparece neste livro apenas para descrever compatibilidade e
migração.
