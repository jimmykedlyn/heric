# FAQ

## O Heric tem vínculo com o Insomnia ou com a Kong?

Não. Heric é um projeto independente que busca compatibilidade.

## Posso continuar usando o Insomnia enquanto uso o Heric?

Sim. A importação copia os dados; o diretório original nunca é modificado.

## Onde ficam meus dados?

Em um diretório de dados do Heric, no local padrão da sua plataforma. Veja
[Requests e environments](requests-and-environments.md) para saber como os
secrets são guardados.

## Quais plataformas são suportadas?

Windows x86_64, Linux x86_64 e macOS em Apple Silicon e Intel.

## E o cloud sync?

Fora de escopo. Veja o `docs/out-of-scope.md` do projeto.
