# Autenticação

A autenticação de request suporta os esquemas do cliente original:

| Esquema | Status |
|---|---|
| Basic | previsto para M3 |
| Bearer | previsto para M3 |
| Digest | previsto para M3 |
| NTLM | previsto para M3 |
| OAuth 1.0 | previsto para M3 |
| OAuth 2.0 (todos os grants) | previsto para M3 |
| AWS SigV4 | previsto para M3 |
| Hawk | previsto para M3 |
| ASAP | previsto para M3 |
| API key | previsto para M3 |
| Netrc | previsto para M3 |

As credenciais digitadas no painel de autenticação não entram nos arquivos
exportados, a menos que você permita, como no comportamento original.
