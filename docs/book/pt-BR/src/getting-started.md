# Primeiros passos

Heric organiza o trabalho como o cliente original: uma **organization**
contém **projects**, um project contém **workspaces**, e um workspace reúne
uma collection de requests, environments e pastas.

1. Crie um project. Um project local é criado para você no primeiro uso.
2. Crie um workspace dentro do project.
3. Um environment base e um cookie jar são criados automaticamente.
4. Adicione um request ao workspace e envie.

A janela principal tem uma barra lateral com suas collections, o editor do
request e um painel de resposta com body, headers e a timeline da última
execução.
