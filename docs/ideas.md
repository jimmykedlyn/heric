# Ideas

Improvements that are out of scope for parity work. Do not implement them
before the corresponding milestone ships; move an entry to a plan when the
time comes.

- A command palette with fuzzy search over collections, requests and
  environments.
- Per-request response history with diffing between two responses.
- A built-in load test mode using the same request definition.
- Plugin system for custom template tags and auth schemes, loaded from a
  sandboxed directory.
- Convert a HAR capture into a collection with grouping heuristics.
